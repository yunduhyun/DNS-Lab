# DNS/RPZ 유해사이트 차단 정책 초안

> 피싱 의심 사이트와 악성 행위 및 지정한 유해 콘텐츠를 제공하는 사이트를 식별하여 DNS/RPZ 차단 대상으로 판단하기 위한 초안이다. 이 문서의 판정 기준을 적용하되, 실제 RPZ 반영 여부와 분석 판정을 구분한다.

## 적용 범위

- 피싱 의심, 정보 탈취, 악성코드 배포 의심, 사기와 기만적 설치 등 보안 위험을 판단한다.
- 성인물, 도박과 베팅 등 2절에 명시한 유해 콘텐츠 유형을 차단 대상으로 판단한다.
- 보안 위협에 따른 차단과 유해 콘텐츠 유형에 따른 차단 사유를 구분한다. 성인물이나 도박으로 분류되었다는 이유만으로 악성코드 배포 사이트라고 보고하지 않는다.
- 조사 브라우저에서 확인한 동작은 사이트의 기능과 동작에 대한 증거로만 사용한다.
- 자료가 없어 확인하지 못한 기능과 행위는 확인한 것으로 보고하지 않는다. 추가 조사가 필요하면 확인할 내용과 이유를 보고한다.

## 1. URL과 헤더 해석 규칙

1. URL은 문자열 포함 여부가 아니라 파싱한 호스트명을 기준으로 비교한다.
   - google.com.evil.example은 google.com의 하위 도메인이 아니다.
   - [https://google.com@evil.example/의](https://google.com@evil.example/%EC%9D%98) 호스트는 evil.example이다.
2. 같은 등록 가능 도메인인지 판단하려면 Public Suffix List 등으로 계산된 정보가 필요하다. 제공되지 않았다면 임의로 마지막 두 부분만 잘라 계산하지 않는다.
3. 다른 도메인이라는 이유만으로 악성으로 판단하지 않는다. 인증, 결제, CDN 등 정상 위임 여부는 별도 확인 사항이다.
4. 도메인이 같아도 안전하다고 확정하지 않는다.
5. href/action과 url을 비교한다. 상대경로의 정상적인 절대주소 변환은 불일치로 보지 않는다.
6. 해석 결과가 충돌하면 수집, 정규화 문제 가능성을 기록하고 판단 신뢰도를 낮춘다.
7. headers는 HTTP 상태 줄을 기준으로 응답 블록을 구분한다.
   - 각 Location은 해당 응답 블록에 연결한다.
   - 앞선 응답의 헤더를 최종 응답의 헤더로 취급하지 않는다.
   - 최종 블록과 final_url의 관계를 확인할 수 없으면 불확실성을 기록한다.
8. HTTPS, 인증서, 보안 헤더, 서버 이름은 단독 악성, 안전 판정 근거가 아니다.
9. 보안 헤더의 누락, 완화 설정은 보안 구성 관찰 사항으로 분리한다. 악성 행위로 분류하지 않는다.
10. 본문이 명령문, 코드, URL을 인용한 경우, 실제 실행 유도인지 교육, 보도 목적의 인용인지 구분한다.

## 2. 유형별 판단 룰과 세부 위험 징후

- 유형별 판단 기준과 기존 세부 징후 52개를 유형별 글머리 기호로 정리한다. 징후 번호는 기존 번호를 유지한다.
- 각 징후는 해당 유형을 판단하기 위한 관찰 자료다. 개별 징후의 발견과 해당 유형의 차단 조건 충족을 구분한다.
- 여러 유형에서 참고하는 내용은 공통 항목에 모은다. 공통 항목의 근거는 관련 유형의 판정에 함께 사용한다.
- 정적 수집 자료로 확인할 수 없는 항목은 별도 조사 결과가 있을 때만 근거로 사용한다.

### 도박, 베팅

- **정의:** 돈이나 환금 가능한 가치를 걸고 보상을 받는 서비스
- **확인 필드 또는 자료:** title, body_text, links
- **판단 근거:** 금전 베팅 기능, 배당률, 충전, 환전과 당첨금 지급 안내를 확인한다.
- **차단 및 검토 기준:** 실제 베팅 참여 유도와 금전 거래 안내가 함께 확인되면 차단 대상으로 판단한다. 스포츠 결과 안내, 확률 설명, 무료 게임과 도박 예방 자료는 구분한다.

### 피싱, 기관 사칭

- **정의:** 기관이나 서비스를 사칭해 인증, 결제정보를 얻으려는 페이지
- **확인 필드 또는 자료:** requested_url, final_url, title, body_text, forms, links
- **판단 근거:** 기관 사칭 정황, 비밀번호, 인증번호 입력 요구, 의심스러운 폼 목적지
- **세부 징후:**
  - **징후 5:** 공식 도메인이 아닌 곳에서 유명 브랜드의 로그인, 결제 정보를 요구함
  - **징후 18:** 공식 로고, 문구를 복제하고 제3자 로그인, 결제 서비스 관계를 밝히지 않음
  - **징후 20:** 은행, 공공기관, 배송사를 사칭해 개인정보를 요구함
  - **징후 21:** 비공식 도메인의 사칭 로그인 화면에서 비밀번호를 요구함
  - **징후 22:** 비밀번호 입력 뒤 문자, 앱 인증번호나 MFA 코드를 다시 요구함
  - **징후 25:** 로그인 폼의 데이터가 관계가 확인되지 않은 외부 도메인으로 전송됨
  - **징후 26:** 사칭 페이지에서 정보를 입력받은 뒤 정상 사이트로 이동해 수집 사실을 감춤
  - **징후 46:** 계정 정지 위협이나 시간 압박으로 즉시 로그인, 결제를 요구함
- **차단 및 검토 기준:** 사칭 정황과 인증정보 또는 결제정보 제출 요구가 함께 확인되면 피싱 의심 사이트로 차단 대상으로 판단한다. 일반 로그인 링크나 유사한 주소만으로 차단하지 않는다.

### 악성코드 배포 의심

- **정의:** 기기 감염을 목적으로 프로그램 설치, 실행을 유도하는 페이지
- **확인 필드 또는 자료:** title, body_text, links, script_urls, headers
- **판단 근거:** 보안 기능 해제 요구, 업데이트 등을 가장한 실행 파일 설치 유도
- **세부 징후:**
  - **징후 28:** 페이지를 방문하자 실행파일, 스크립트, 앱 설치 파일이 자동으로 다운로드됨
  - **징후 29:** 신뢰할 수 있는 검사에서 사이트가 제공한 파일이 악성으로 확인됨
  - **징후 30:** 가짜 업데이트, 코덱, 문서 뷰어를 내세워 출처 불명 설치 파일을 제공함
  - **징후 32:** 설치 후 동의 없이 브라우저 설정을 바꾸거나 다른 프로그램을 추가함
  - **징후 33:** 설치 전에 백신이나 브라우저 보호 기능을 끄라고 요구함
- **차단 및 검토 기준:** 구체적인 기만, 설치 유도가 있으면 제한 또는 검토. 파일, 코드 분석이 없으므로 악성코드라고 확정하지 않음

### 가짜 보안 경고, 기술지원 사기

- **정의:** 감염이나 오류를 가장해 전화, 결제, 원격제어를 유도하는 페이지
- **확인 필드 또는 자료:** title, body_text, links
- **판단 근거:** 감염 단정, 긴급 경고, 지원 번호 전화, 결제, 원격접속 요구
- **세부 징후:**
  - **징후 19:** 가짜 브라우저, 운영체제 경고로 전화를 걸거나 프로그램을 설치하라고 유도함
  - **징후 34:** 가짜 감염 경고로 원격지원 프로그램 설치나 전화 통화를 유도함
- **차단 및 검토 기준:** 허위 감염 경고 정황과 조치 요구가 결합되면 차단 또는 우선 검토

### 금전 편취 의심

- **정의:** 허위 거래, 투자, 보상을 빌미로 송금을 유도하는 페이지
- **확인 필드 또는 자료:** title, body_text, links, forms
- **판단 근거:** 출금 전 선입금 요구, 보상 지급 수수료, 반복적인 추가 입금 압박
- **세부 징후:**
  - **징후 39:** 유명 상품을 시장가보다 현저히 낮은 가격으로 광고함
  - **징후 40:** 기프트카드, 송금, 암호화폐처럼 분쟁 해결이 어려운 방식만 결제 수단으로 허용함
  - **징후 41:** 결제 수취인이나 상호가 사이트와 설명 없이 다름
  - **징후 42:** 배송, 반품, 환불 규정이 없거나 페이지마다 서로 모순됨
  - **징후 43:** 사업자 주소, 전화번호가 허위이거나 무관한 업체 정보임
  - **징후 44:** 리뷰 문구가 복제됐거나 짧은 시간에 비정상적으로 몰린 정황이 있음
  - **징후 45:** 광고와 실제 페이지의 상품 또는 판매자가 다름
  - **징후 47:** 당첨, 환급, 지원금을 약속한 뒤 수수료, 세금, 배송비를 먼저 요구함
- **차단 및 검토 기준:** 구체적인 편취 정황이 있으면 제한 또는 검토. 낮은 가격, 수익 홍보만으로 확정하지 않음

### 기만적 설치 의심

- **정의:** 설치 대상이나 필요성을 속여 프로그램 설치를 유도하는 페이지
- **확인 필드 또는 자료:** body_text, links, script_urls
- **판단 근거:** 콘텐츠 이용을 위한 불필요한 설치 요구, 표시 내용과 다른 다운로드 유도
- **세부 징후:**
  - **징후 31:** 다운로드 버튼 설명과 실제로 연결되는 파일이나 도메인이 다름
- **차단 및 검토 기준:** 설치를 속이는 정황이 확인되면 해당 링크, 페이지 제한 또는 검토. 일반 설치 안내는 제외

### 민감정보 탈취 의심

- **정의:** 목적을 속여 인증정보나 자산 접근 정보를 제출하도록 하는 페이지
- **확인 필드 또는 자료:** title, body_text, forms, links
- **판단 근거:** 지갑 복구 문구, 개인키 제출, 보상을 빌미로 인증번호 요구
- **세부 징후:**
  - **징후 23:** 계정 복구를 이유로 복구 코드, 개인키, 시드 구문을 요구함
  - **징후 24:** 서비스 목적과 무관하게 카드 전체 번호, 보안코드, 은행 PIN을 요구함
  - **징후 27:** 쿠폰, 계정 연결 등을 이유로 다른 서비스의 비밀번호까지 요구함
  - **징후 48:** 서비스 목적과 무관한 민감 개인정보를 과도하게 요구함
  - **징후 49:** 개인정보 처리 안내가 없거나, 실제 데이터 수집이 안내 내용과 다름
- **차단 및 검토 기준:** 정보 탈취 목적이 명확하면 차단. 보관 안내, 예방 교육, 정상 정보 수집은 구분

### 성인 콘텐츠

- **정의:** 노골적인 성적 콘텐츠 제공, 판매를 주목적으로 하는 페이지
- **확인 필드 또는 자료:** title, body_text, links
- **판단 근거:** 노골적인 성적 콘텐츠의 재생, 구매, 유료 가입과 제공 목록을 확인한다.
- **차단 및 검토 기준:** 노골적인 성적 콘텐츠의 제공 목적이 명확하면 차단 대상으로 판단한다. 성인 관련 단어, 성인 인증 화면이나 외부 광고 하나만으로 판단하지 않는다. 의학, 성교육과 상담은 제외한다.

### 성착취, 비동의 성적 콘텐츠 의심

- **정의:** 성착취물이나 동의 없는 성적 콘텐츠를 제공, 거래하는 페이지
- **확인 필드 또는 자료:** title, body_text, links
- **판단 근거:** 해당 콘텐츠의 제공, 판매, 유포를 명시적으로 제안
- **차단 및 검토 기준:** 명확한 제공 정황이 있으면 차단 및 우선 검토. 보도, 피해 신고, 삭제 지원은 제외

### 폭력, 자해 실행 독려

- **정의:** 사람에게 위해를 가하는 행동을 직접 권유하거나 지원하는 페이지
- **확인 필드 또는 자료:** title, body_text, links
- **판단 근거:** 특정 대상 공격 독려, 실행자 모집, 자해, 자살 실행 권유
- **차단 및 검토 기준:** 직접적인 실행 독려가 명확하면 차단 및 우선 검토. 예방, 상담, 도움 요청, 보도는 제외

### 가짜 인증을 통한 명령 실행 유도

- **정의:** 사람 확인이나 오류 해결을 가장하여 운영체제 명령 실행을 유도하는 페이지다.
- **확인 필드 또는 자료:** title, body_text, links
- **판단 근거:** CAPTCHA 통과나 오류 해결을 이유로 실행 창 또는 터미널을 열어 명령을 붙여넣고 실행하도록 요구한다.
- **세부 징후:**
  - **징후 51:** 사람 확인, CAPTCHA 통과나 오류 해결을 가장하여 실행 창 또는 터미널에 명령을 붙여넣고 실행하도록 요구한다. 정상적인 개발 문서와 교육 목적의 인용은 구분한다.
- **차단 및 검토 기준:** 인증을 가장한 기만과 명령 실행 요구가 함께 확인되면 차단 대상으로 판단한다. 개발 문서, 정상적인 문제 해결 안내와 보안 교육의 인용은 구분한다.

### 계정 연동을 가장한 접근 권한 탈취

- **정의:** 계정 연동 동의를 악용해 외부 앱에 데이터 접근 권한을 주도록 속이는 페이지다.
- **확인 필드 또는 자료:** requested_url, final_url, title, body_text, links
- **판단 근거:** 문서 열람이나 보상을 내세워 설명한 기능과 무관한 메일 또는 파일 접근 권한을 요구하며, 앱이나 게시자 사칭 등 기만 정황이 확인된다.
- **세부 징후:**
  - **징후 52:** 문서 열람이나 보상을 내세워 외부 앱에 메일 또는 파일 접근 권한을 주도록 유도하며, 앱이나 게시자 사칭 등 기만 정황과 설명한 기능에 부합하지 않는 권한 요구가 함께 확인된다. 정상적인 계정 연동과 구분한다.
- **차단 및 검토 기준:** 권한 요청만으로 차단하지 않는다. 사칭 또는 기만 정황과 기능에 부합하지 않는 권한 요구가 함께 확인되면 동의 피싱 의심으로 차단 대상으로 판단한다. 근거가 부족하면 검토한다.

### 공통 보조 징후

- **정의:** 여러 위험 유형을 검토할 때 참고하는 주소와 브라우저 동작의 징후다.
- **확인 필드 또는 자료:** requested_url, final_url, title, body_text, links, headers 및 별도로 확인한 브라우저 관찰 자료
- **세부 징후:**
  - **징후 1:** 공식 도메인과 한두 글자만 다르거나 글자 순서를 바꾼 주소
  - **징후 2:** 브랜드명은 주소 앞부분에 있지만 실제 등록 도메인은 무관함
  - **징후 3:** 라틴, 키릴 문자 등 비슷하게 생긴 다른 문자를 섞어 공식 주소처럼 보이게 함
  - **징후 4:** @ 앞부분이 신뢰할 만한 주소처럼 보이도록 구성됨
  - **징후 6:** 단축 URL이 로그인, 결제 페이지로 연결되어 최종 목적지를 숨김
  - **징후 7:** 브랜드명에 support, verify, secure, 숫자 등을 붙인 유사 주소
  - **징후 8:** 철자만 다른 여러 도메인이 같은 브랜드 복제 페이지를 제공함
  - **징후 9:** 링크를 따라가면 여러 도메인을 거쳐 예상 밖의 로그인, 결제 페이지에 도착함
  - **징후 10:** 링크에 보이는 문구와 실제 도착 주소가 다름
  - **징후 11:** 최근 생성된 도메인이 유명 브랜드를 사칭함. 도메인 생성일만으로는 단정하지 않음
  - **징후 12:** 비슷한 도메인이 짧은 기간에 다수 등록되고, 그중 사칭 페이지가 확인됨
  - **징후 13:** TLS 인증서가 있어도 도메인과 주장하는 회사의 관계를 확인할 수 없음
  - **징후 35:** 알림 허용을 강요하고, 이후 사기성 알림을 보냄
  - **징후 36:** 콘텐츠와 무관하게 카메라, 마이크, 위치, 클립보드 권한을 요구함
  - **징후 37:** 반복 팝업이나 전체 화면 고정으로 창 닫기, 뒤로 가기를 방해함
  - **징후 38:** 방문 환경에 따라 위험한 콘텐츠를 다르게 보여주는 정황이 있음
- **차단 및 검토 기준:** 이 항목의 징후 하나만으로 자동 차단하지 않는다. 관련 유형의 차단 기준과 실제 관찰 근거를 함께 확인한다.

### 공통 외부 확인 근거

- **정의:** 보안 경고, 평판, 공식 공지와 재현 결과 등 별도로 확인해야 하는 근거다.
- **확인 필드 또는 자료:** 실제로 확보한 브라우저 경고, 평판 조회 결과, 공식 공지, 피해 신고와 안전한 검사 결과
- **세부 징후:**
  - **징후 14:** 브라우저가 피싱, 악성 사이트 경고를 표시함
  - **징후 15:** 서로 독립적인 복수의 보안 평판 서비스에서 피싱, 악성 사이트로 확인됨
  - **징후 16:** 해당 기관, 브랜드나 보안 기관이 그 URL을 사칭 사이트로 직접 공지함
  - **징후 17:** 구체적인 URL과 계정 탈취, 결제 피해 행위를 제시하는 신고가 반복됨
  - **징후 50:** 안전한 검사 환경에서 피싱, 악성코드, 사기 동작을 재현 가능하게 확인함
- **차단 및 검토 기준:** 자료의 출처, 해당 URL이나 파일과의 일치 여부 및 관찰 범위를 확인하고 관련 유형의 차단 기준에 적용한다. 실제 조회하거나 검사하지 않은 결과는 확인한 것으로 보고하지 않는다.

## 3. 증거와 판정 기준

### 증거 적용 원칙

- 판정에는 근거가 된 수집 필드와 관찰 내용을 함께 제시한다.
- 유사한 도메인, 외부 링크, HTTPS 사용 여부 등 단독으로 위험을 확정하기 어려운 신호만으로 차단하지 않는다.
- 피싱은 사칭 정황과 정보 제출 요구 등 구체적인 근거의 결합을 기준으로 의심 여부를 판단한다. 실제 계정 탈취 피해가 발생해야만 차단할 수 있는 것은 아니다.
- 성인물과 도박 등 지정한 유해 콘텐츠는 해당 콘텐츠나 서비스의 제공 목적을 기준으로 판단한다. 교육, 예방, 상담과 보도 목적은 구분한다.
- 확인하지 않은 평판, 등록 정보와 실행 결과는 추측하지 않는다.

### 조치

- review: 위험 정황의 확인에 필요한 핵심 정보가 부족하거나, 원본 콘텐츠 미확보, 인증 화면, 접속 오류 등으로 최종 판단이 어려워 관리자 검토가 필요한 경우다. 검토가 필요한 이유를 reason과 보고서에 구체적으로 기록한다.
- allow: 분석 대상 사이트의 실제 콘텐츠를 확보하여 검토했고, 해당 자료에서 유형별 차단 조건에 해당하는 근거가 발견되지 않은 경우다. 안전 보증은 아니다.
- decision은 block, review, allow 중 하나만 반환한다. 자료 부족은 별도 판정값을 만들지 않고 review로 반환한다.

### 원본 사이트와 최종 도착 페이지의 판단

- 판정 대상은 domain에 지정된 원본 사이트다.
- 원본 사이트 접속 결과가 프로젝트에서 신뢰 대상으로 지정한 차단 안내 도메인으로 연결되고, 본문에서도 해당 접속에 대한 유해사이트 차단 안내가 확인되면 block으로 판단한다.
- 이 경우 차단 근거는 외부 차단 안내가 확인되었다는 사실이다. 원본 콘텐츠를 직접 확인했다고 보고하지 않는다.
- 사이트 유형은 외부 차단 안내가 확인된 사이트로 기록한다. 별도 근거 없이 피싱, 악성코드, 도박 등으로 확정하지 않는다.
- 본문의 차단 안내 문구만으로 위 기준을 충족했다고 판단하지 않는다. final_url의 호스트가 프로젝트에서 지정한 차단 안내 도메인인지 함께 확인한다.
- 위 차단 조건을 충족하면 추가 조사 없이 needs_investigation은 false로, investigation_url은 빈 문자열로 반환한다.
- 차단 안내가 아닌 무관한 사이트로 이동했고 원본 콘텐츠를 확보하지 못했다면 review로 판단하고, 원본 콘텐츠를 확인하지 못했다는 이유를 기록한다.
- 인증 화면, 접속 오류 또는 빈 페이지만 확보했다는 이유로 block이나 allow로 판단하지 않는다.

### 추가 원칙

- 단독으로 위험을 확정하기 어려운 약한 증거만으로 block하지 않는다.
- 보안상 위협과 지정한 유해 콘텐츠에 따른 제한을 구분한다.
- 유명 도메인이라는 이유로 자동 허용하지 않는다.
- 일부 페이지의 증거를 전체 도메인으로 확대하지 않는다.
- confidence는 관찰 범위 내 판정의 확실성이다. 통계적인 악성 확률이 아니다.
- 본문 데이터가 충분하면 스크립트 코드가 없다는 이유만으로 review로 판정하지 않는다. 확보한 콘텐츠에 유형별 판단 기준을 적용한다.

## 4. 수집 필드와 사용 방법

- **domain**
  - 담긴 정보: 수집 대상 도메인
  - 판단에 사용하는 방법: 분석 대상을 식별하고 요청 URL과 비교
- **job_id**
  - 담긴 정보: 수집 작업 식별자
  - 판단에 사용하는 방법: 결과를 원래 작업과 연결. 위험 판단에는 사용하지 않음
- **dns.A, dns.AAAA**
  - 담긴 정보: DNS 조회 상태와 IPv4, IPv6 주소
  - 판단에 사용하는 방법: 주소 조회 여부 확인. IP만으로 악성 여부를 판단하지 않음
- **requested_url**
  - 담긴 정보: 처음 요청한 주소
  - 판단에 사용하는 방법: 최초 접속 대상 확인
- **final_url**
  - 담긴 정보: 최종 도착 주소
  - 판단에 사용하는 방법: 접속 후 어디로 이동했는지 확인
- **headers**
  - 담긴 정보: HTTP 응답 정보
  - 판단에 사용하는 방법: 상태 코드, 이동 주소인 Location, 콘텐츠 형식 등을 확인
- **title**
  - 담긴 정보: 페이지 제목
  - 판단에 사용하는 방법: 페이지가 어떤 기관, 서비스, 콘텐츠라고 주장하는지 확인
- **script_urls**
  - 담긴 정보: 스크립트 파일 주소 목록
  - 판단에 사용하는 방법: 어떤 주소의 스크립트를 포함하는지 확인. 코드 내용과 동작은 알 수 없음
- **links[].text**
  - 담긴 정보: 링크에 표시된 문구
  - 판단에 사용하는 방법: 사용자를 어떤 행동으로 유도하는지 확인
- **links[].href**
  - 담긴 정보: HTML에 적힌 원본 링크
  - 판단에 사용하는 방법: 원래 연결 값 확인. 상대경로일 수 있음
- **links[].url**
  - 담긴 정보: 수집기가 해석한 링크 주소
  - 판단에 사용하는 방법: 실제 연결 대상으로 해석된 주소 확인
- **forms[].action**
  - 담긴 정보: HTML에 적힌 폼 전송 목적지
  - 판단에 사용하는 방법: 원본 전송 경로 확인
- **forms[].url**
  - 담긴 정보: 수집기가 해석한 폼 전송 주소
  - 판단에 사용하는 방법: 입력 정보를 어디로 보내도록 되어 있는지 확인
- **forms[].method**
  - 담긴 정보: GET, POST 등 전송 방식
  - 판단에 사용하는 방법: 전송 방식 확인. 방식만으로 악성 여부를 판단하지 않음
- **body_text**
  - 담긴 정보: 추출한 본문
  - 판단에 사용하는 방법: 서비스 목적, 정보 입력, 송금, 설치 요구와 그 맥락 확인

## 5. 추가 조사와 DNS/RPZ 차단 범위

- 최초 수집 자료에서 차단 근거가 충분하면 추가 조사 없이 차단 대상으로 분류한다.
- 핵심 근거가 애매하고 허용된 추가 조사로 확인할 수 있으면 조사 대상 URL과 이유를 남겨 MCP 조사를 요청한다.
- 추가한 징후가 title, body_text, links 등 최초 수집 자료에 있으면 해당 자료로 판단한다. 핵심 내용이 JavaScript 실행 후에 나타나는 경우에는 MCP 브라우저 조사 후보로 남긴다.
- 조사 과정에서 로그인, 계정 접근 권한 승인, 결제와 운영체제 명령 실행은 수행하지 않는다. 승인 후에만 확인 가능한 권한 화면과 동작은 확인 불가로 남긴다.
- 동의 피싱 과정에서 정상적인 인증 제공자의 도메인으로 이동할 수 있으므로, 그 도메인을 악성 도메인으로 자동 지정하지 않는다. 기만이 관찰된 사이트와 요청 앱을 구분하고 기존 DNS/RPZ 차단 범위 원칙을 적용한다.
- 추가 조사 후에도 핵심 근거가 부족하면 review로 판단하고 관리자 확인이 필요한 이유를 기록한다. needs_investigation은 false로, investigation_url은 빈 문자열로 반환한다. 조사에 실패했다는 이유만으로 유해사이트로 단정하지 않는다.
- DNS/RPZ 차단 대상은 도메인 이름이다. 특정 URL 경로의 문제를 발견한 경우 해당 도메인 차단이 다른 정상 페이지에 미치는 범위를 함께 검토한다.
- 외부 링크나 리다이렉트에서 발견한 위험을 최초 요청 도메인에 자동으로 귀속하지 않는다. 위험이 관찰된 주소와 차단 후보 도메인을 구분한다.
